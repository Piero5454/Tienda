# Plano Digital

Landing page para promocionar servicios de desarrollo de sitios web, apps y dashboards.

Sitio publicado: https://piero5454.github.io/Tienda/

## Estructura

```
index.html      Contenido de la página
css/styles.css  Estilos (colores, tipografías, diseño responsive)
js/main.js      Selector Web/App/Dashboard y formulario de contacto por WhatsApp
.nojekyll       Indica a GitHub Pages que publique los archivos tal cual
```

## Personalizar

- Nombre de la marca, correo y WhatsApp: en `index.html`.
- Número de WhatsApp del formulario: variable `WHATSAPP` en `js/main.js`.
- Colores y tipografías: variables al inicio de `css/styles.css`.
